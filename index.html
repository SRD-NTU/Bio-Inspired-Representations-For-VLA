Additional Experimental Details

Scope. HERo (Human-like Eyes for Robots) is the training-free visual front end introduced in the main paper. AdVisR denotes its Adaptive Visual Representation module. HERo operates with frozen VLA policy weights and requires no additional training. For the real-world experiments, task-specific policies are fine-tuned before evaluation and subsequently frozen, as described in Section S4.

S1. Evaluation Protocol

Common protocol. We evaluate HERo on LIBERO and SIMPLER–WidowX. Within each backbone, we compare visual representations under matched visual budgets while keeping the policy frozen. Results on both simulation benchmarks are averaged over three evaluation seeds. Full-resolution performance is reported as a reference.

For an RGB observation It ∈ ℝH×W×3 and visual budget β ∈ (0, 1], the uniform representation retains

Nb = min{HW, max(1, round(βHW))}

regularly distributed samples. The resulting low-resolution grid is bilinearly reconstructed to the original image size to match the frozen VLA input size. The comparison follows the information-matched image protocol described in the main paper: budgeted representations allocate the available visual information differently while operating at the same nominal pixel budget.

LIBERO. We evaluate the four LIBERO suites: Spatial, Object, Goal, and Long. Each suite contains ten tasks. We use 50 rollouts per task, resulting in 500 rollouts per suite, and average the results over three evaluation seeds. We report success rates and the average number of environment steps over successful rollouts, as in Table II of the main paper.

The primary HERo comparisons use InstructVLA (1.5B parameters), SmolVLA (0.5B), and TurboVLA (0.2B). Table II additionally reports full-resolution and Uniform results for OpenVLA and UniVLA. The token-pruning study in Table III evaluates OpenVLA with SP-VLA and π0.5 with Grid-16 and Grid-4. HERo and Uniform are compared within the corresponding backbone, visual budget, and token-pruning setting.

SIMPLER–WidowX. We use the WidowX+Bridge setup in SIMPLER, with 24 rollouts per task and results averaged over three evaluation seeds. The manipulation tasks illustrated in Fig. 3(a) are placing an eggplant in a basket, placing a spoon on a tablecloth, stacking a green cube on a yellow cube, and placing a carrot on a plate.

The primary HERo comparisons use CronusVLA (0.5B parameters) and MiniVLA (1B). We report average success rates for each visual budget. Table I also includes full-resolution and Uniform reference results for OpenVLA, SpatialVLA, and UniVLA.

Visual budgets. The main LIBERO comparisons use β ∈ {1%, 3%, 5%, 10%, 20%}, while the main SIMPLER comparisons use β ∈ {5%, 10%, 20%}. Both include full-resolution reference results. The extended TurboVLA analysis on LIBERO examines budgets from 1% to full visual input, including budgets above 20%, to study how performance changes as more visual information is retained.

S2. HERo and Baseline Representations

Policy-guided relevance. HERo converts model-specific relevance signals from the frozen VLA into a normalized coarse spatial map. For policies exposing causal action-token attention, the signal aggregates attention from action tokens to the latest visual-token span across selected layers and heads. Other policy backends provide native relevance signals, such as fusion attention or cognition-token-to-vision attention, through the same coarse-map interface.

Policy relevance becomes available only after inference and therefore guides subsequent policy queries. The first query, or a query with missing feedback, defaults to uniform processing. At query t, HERo combines temporally smoothed relevance from earlier queries with an image-derived distractor prior from the current observation. It then extrapolates the relevance field, blends the extrapolation with the current field, and uses non-maximum suppression to extract up to K dominant candidate focus regions.

AdVisR. AdVisR maps the selected focus locations to the normalized complex plane and constructs a multi-focus Möbius field. For a focus uk, the transformation is

qk(z) = st (z − uk) / (1 − ukz)
gk(z) = (qk(z) + uk) / (1 + ukqk(z))

Here, st ∈ [smin, 1] controls concentration, with smaller values producing stronger magnification around the selected focus.

The focus fields are blended using Gaussian weights and an identity component:

Gt(z) = (bz + ∑k=1Kₜ wk(z)gk(z)) / (b + ∑k=1Kₜ wk(z))
wk(z) = exp(−‖z − uk‖22 / (2σ2))

where Kt ≤ K, σ controls the spatial extent of each focus, and b > 0 preserves global scene structure away from the selected regions.

The image is warped, area-downsampled to Hb × Wb, bilinearly reconstructed to the original image size, and warped back using the inverse mapping. The budgeted dimensions are

Hb = max(1, round(H√β)),   Wb = max(1, round(W√β))

Thus, HbWb ≈ βHW, with integer rounding determining the realized grid size. These operations redistribute spatial detail without introducing an additional neural network.

Focused and contextual variants. HERof and HERoc use the same interaction-strength signal but differ in their concentration coefficients. The focused variant sets κt(focus) = 1; its actual concentration still varies with the interaction-strength signal. The contextual variant initializes κ0(context) = 0 and updates this coefficient online, subject to an upper bound κmax < 1. This limits its concentration relative to the focused variant and preserves broader scene context.

The two representations are independently passed to the frozen VLA and evaluated as separate variants. HERo* in Tables I and II is a hypothetical oracle that succeeds when either variant succeeds. It characterizes their complementary success patterns rather than an implemented test-time selection or fallback mechanism.

Baseline Methods

For fair comparison, we extend the information-matched image protocol of Gizdov et. al. (2025)[1] to vision-language-action setting. All methods operate under the same pixel budgets, differing only in how visual information is allocated across space and time.

We compare HERo against four representative visual allocation strategies: Uniform, Foveated Representation (Gizdov et al., 2025)[1], Sunflower-Inspired Representation (Killick et al., 2023)[2], and SALISA (Ehteshami et al., 2022)[3]. Uniform representation evenly distributes the available visual budget, while the remaining baselines use different forms of non-uniform spatial allocation.

Uniform Sampling. We include uniform sampling as the main budget-matched baseline, where the same total pixel budget is distributed evenly across the entire observation. This provides a simple reference to measure whether non-uniform spatial allocation offers any benefit over treating all image regions equally.

Static Foveated. We implement the static-foveated baseline following Gizdov et al. (2025)[1], where higher spatial resolution is assigned around a fixed fixation point and gradually reduced toward the image boundary. Following the original setting, the fixation is kept at the image center throughout the evaluation. This baseline tests whether a fixed center-focused representation is sufficient without adapting to the current manipulation task.

Sunflower Inspired. We adopt the biologically inspired sunflower-phyllotaxis sampling pattern proposed by Killick et al. (2023)[2]. The method distributes samples non-uniformly across the visual field using a structured pattern inspired by biological vision. Similar to the static-foveated baseline, we use it only as an input transformation and keep the sampling pattern fixed during evaluation. This allows us to compare HERo against a biologically inspired but non-adaptive representation.

SALISA. We further compare against SALISA (Ehteshami et al., 2022)[3], a saliency-based adaptive sampling method that assigns more spatial resolution to visually salient regions while reducing resolution in less salient areas. Unlike the fixed baselines above, SALISA adapts its sampling according to the visual content of each observation. It therefore provides a stronger comparison for evaluating whether HERo's action-conditioned adaptation offers advantages beyond image-level visual saliency.

Token Pruning. The token-pruning study additionally evaluates whether HERo's adaptation of the visual input complements subsequent visual-token reduction. Comparisons are reported for the corresponding SP-VLA[4] and π0[5] settings, with Grid-16 and Grid-4[6] used for π0 in Table III.

S3. Ablations and Measurements

Component ablation. Figure 5 evaluates HERof with MiniVLA on SIMPLER–WidowX at 5%, 10%, and 20% visual budgets. The ablations remove the image-derived prior, temporal smoothing, or VLA feedback individually to assess their contributions to manipulation success.

Trajectory efficiency. For LIBERO, the step statistic is the average number of environment steps over successful rollouts only. It is reported alongside success rate because the set of successful rollouts can differ between methods. A lower step count therefore characterizes successful execution and should be interpreted together with the corresponding success rate.

Runtime. The experimental hardware comprises four NVIDIA RTX 5090 GPUs with 32 GB of VRAM each. At 224 × 224 resolution and β = 0.10, HERo adds 1.76 ms per policy query on an NVIDIA RTX 5090. This overhead consists of non-neural image warping and tensor operations; HERo introduces no additional neural-network FLOPs. The reported value measures HERo's added processing overhead, rather than the end-to-end inference latency of every evaluated VLA backbone.

S4. Real-World Manipulation Protocol

Tasks and policy training. We validate HERof with SmolVLA on two physical manipulation tasks: Apple-to-Plate Placement and Lid Closing. The latter requires overcoming spring resistance and applying sufficient downward force to fully close the container.

For each task, we independently fine-tune a task-specific policy from the same pretrained SmolVLA base checkpoint, whose vision-language backbone is SmolVLM2-500M-Video-Instruct. Only the action expert and state projection are fine-tuned. Each policy is trained for 20,000 optimization steps with batch size 16, AdamW, a learning rate of 1 × 10−4, cosine decay, and 1,000 warm-up steps on a single NVIDIA RTX 5090 GPU.

Representation evaluation. The fine-tuned policy weights are frozen during evaluation, and the same task-specific policy is used across visual representations. We compare full-resolution inference with Uniform and HERof, with the latter two using a 10% visual budget.

We evaluate Apple-to-Plate Placement over 12 episodes and Lid Closing over 15 episodes, and report average success rates across three independent evaluation sets. Task-policy fine-tuning is separate from HERo: HERo changes the visual representation supplied to the frozen policy without requiring additional policy training.
